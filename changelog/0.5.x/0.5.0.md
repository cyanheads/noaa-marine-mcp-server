# 0.5.0 — 2026-09-17

## Added

- **`prediction_class`** (+ `reference_id` on tide rows, per-bin `bins[]` on current rows) on `noaa_marine_find_stations` and the station resource — a tide station is `reference` or `subordinate`, a current bin `harmonic`, `subordinate`, or `weak_and_variable` (#26, #27)
- **`noaa_marine_get_water_level`** gains `interval`: `6min` (default), `hourly`, `high_low`, and `daily_mean`, each with its own CO-OPS range ceiling and datum set (#30)
- **`noaa_marine_get_currents`** gains `bin` to select a depth bin; the answered bin and its depth are echoed on every response (#27)
- **Paging** — `noaa_marine_get_water_level`, `noaa_marine_get_tide_predictions`, and `noaa_marine_get_currents` accept `offset`/`limit` and report `rows_matched`, `rows_returned`, `page_offset`, and `next_offset` for a series too large for one response (#18)
- **`gaps_dropped`** on `noaa_marine_get_water_level` counts sensor slots CO-OPS returned with no reading (#22)
- **`subordinate_no_6min`** pre-flight on `noaa_marine_get_tide_predictions` rejects a 6-minute request for a subordinate station before the upstream call, naming its reference station (#26)
- **New typed errors**: `datum_unavailable`, `bin_unavailable`, `predictions_unavailable` (#25, #27, #26); `great_lakes_only` and `verified_data_lag` on `noaa_marine_get_water_level` (#30)

## Changed

- **Datum enums** are per-tool now: `noaa_marine_get_tide_predictions` accepts MLLW, MHHW, MHW, MTL, MSL, MLW, DTL, NAVD, STND, CRD; `noaa_marine_get_water_level` additionally accepts IGLD, LWD, LWI, HWI (#25)
- **`noaa_marine_get_currents`** returns a success (empty events plus CO-OPS's own statement in the notice) for a weak-and-variable station instead of throwing `no_predictions` (#26)
- **`noaa_marine_get_water_level`**'s `predictions_status` reports `empty` for a series CO-OPS says it never publishes, distinct from `unavailable` for a failed fetch (#26)
- **`noaa_marine_get_tide_predictions`** reports `no_predictions` for a Great Lakes station instead of `station_not_found` (#26)

## Removed

- **`CD`** dropped from the `noaa_marine_get_tide_predictions` and `noaa_marine_get_water_level` datum enums — CO-OPS never accepted it (#25)

## Fixed

- **`noaa_marine_get_currents`** 6-minute rows report speed in cm/s under `metric`, not the previously mislabeled m/s, and each row now carries its own `flood`/`ebb`/`slack` type and the correct signed direction (#19)
- **`noaa_marine_get_currents`** MAX_SLACK events no longer drop a 0° mean bearing — the bearing fields were read as strings, so a numeric zero was silently treated as falsy

## Dependencies

- `@types/node` ^26.2.0 → ^26.5.1
