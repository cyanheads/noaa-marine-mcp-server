# 0.7.0 — 2026-10-28

## Added

- **`noaa-marine-guide` skill** is served over MCP through `createApp({ skills })` (framework 0.13.18). `resources/list` gains `skill://noaa-marine-guide/SKILL.md`, `resources/templates/list` gains `skill://{+path}`, and `initialize` capabilities advertise the `io.modelcontextprotocol/skills` extension. The skill also ships in the npm package, the Docker image, and the `.mcpb`.
- **Agent Plugins** root `plugin.json` and `mcp.json`.

## Changed

- **`noaa_marine_find_stations` description and the server `instructions`** now say `query` matches station names and IDs, not places, so a town or marina needs geocoding to coordinates first. They previously said the tool resolves "a place name".
- **Enrichment trailer string values** render in `content[]` as code literals (framework 0.13.18), e.g. ``**predictions_status:** `empty` `` from `noaa_marine_get_water_level` at a station with no tide predictions. `structuredContent` is unchanged.
- **The `.mcpb`** no longer carries the framework's build-only files (framework 0.13.18), and keeps the MCP SDK's `dist/ext/skills/` runtime that serving skills needs, via a local fix to the copied bundle cleaner and packaging check ([cyanheads/mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794)).
- **README Getting started** is restructured: hosted `claude mcp add`, local `npx`, one stdio JSON block; Docker uses the published image.
- **Maintenance:** `docs/design.md` corrections; framework skills re-synced; `bunfig.toml` release-age guard set to 1 day; the bug-report form uses one Environment table.

## Fixed

- **HTTP transport no longer retains memory per request.** Over Streamable HTTP, framework 0.13.16 (shipped in 0.6.2) held about 71 KiB per request through its shutdown signal, so heap grew with sustained traffic. Framework 0.13.17 releases each request's signal when its response ends ([cyanheads/mcp-ts-core#786](https://github.com/cyanheads/mcp-ts-core/issues/786)).

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.13.16 → ^0.13.18.
