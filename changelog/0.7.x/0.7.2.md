# 0.7.2 — 2026-11-13

## Added

- **Water-level extrema** report the highest and lowest observations and timestamp the peak positive and negative residuals across the full series, before paging ([#63](https://github.com/cyanheads/noaa-marine-mcp-server/issues/63)).

## Changed

- **Build tooling** raises the minimum Bun version to 1.4.4 and updates the framework skills, package checks, and release scripts.
- **MCPB packaging** removes dependency-root agent docs while keeping nested SDK runtime modules.
- **JWT configuration example** documents the expected audience and issuer settings.

## Fixed

- **Subordinate current bins** return CO-OPS max/slack fallback rows in `events` with a notice when a `6min` request yields events ([#54](https://github.com/cyanheads/noaa-marine-mcp-server/issues/54)).
- **6-minute current ranges** enforce CO-OPS's 31-day span and report upstream range rejections as `date_range_exceeded` ([#55](https://github.com/cyanheads/noaa-marine-mcp-server/issues/55)).
- **Water-level datums** reject `LWI` and `HWI`, which are lunitidal intervals measured in hours and available through monthly means ([#56](https://github.com/cyanheads/noaa-marine-mcp-server/issues/56)).
- **Retired gauges** return the removal date and a nearby-gauge search for post-retirement water-level and monthly-mean requests. Historical requests retain their existing recovery ([#57](https://github.com/cyanheads/noaa-marine-mcp-server/issues/57)).
- **NDBC observations** include `observation_age_minutes` and warn when conditions, current profiles, or ocean observations are more than three hours old ([#58](https://github.com/cyanheads/noaa-marine-mcp-server/issues/58)).
- **Station searches** report how many names or IDs matched when other filters exclude every match ([#59](https://github.com/cyanheads/noaa-marine-mcp-server/issues/59)).
- **Partial water-level and monthly-mean results** report the last available observation when a recent range ends before the requested final slot and explain that later data may still await verification ([#60](https://github.com/cyanheads/noaa-marine-mcp-server/issues/60)).
