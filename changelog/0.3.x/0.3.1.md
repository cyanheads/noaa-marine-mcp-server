# 0.3.1 — 2026-08-24

## Added

- **MCP cache hints** — definition lists advertise a 24-hour public TTL, while station metadata advertises a 6-hour public TTL to MCP 2026-07-28 clients.
- **Community health files** — adds contribution guidance and a code of conduct; private vulnerability reports use `security@caseyjhand.com`.

## Changed

- **MCP protocol behavior** — `@cyanheads/mcp-ts-core` `^0.10.14 → 0.12.3` serves MCP 2026-07-28 and 2025-era clients, rejects undeclared root tool arguments, and declares the structured error envelope.
- **HTTP sessions** — `.env.example`, the Docker image, and README now explicitly use `MCP_SESSION_MODE=stateless`; the framework's `auto` schema default remains documented as resolving to stateful.
- **Framework contracts** — services pass the unified `Context` directly, and CO-OPS/NDBC error mapping reads the canonical `data.status` field.
- **Project tooling** — adopts the current mcp-ts-core TypeScript, packaging, MCPB cleanup, dependency, documentation, and skill scaffolds.
